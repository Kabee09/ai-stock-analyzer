# 📈 AI Stock Analyzer

An AI-powered stock analysis tool built with Python, Streamlit, and Claude AI.
Fetches real-time market data and generates intelligent investment insights.

## 🚀 Features
- Real-time stock data via Yahoo Finance
- Interactive candlestick charts with Plotly
- AI-powered analysis powered by Claude (Anthropic)
- Price trends, key observations, risk assessment
- Market sentiment indicator (Bullish/Neutral/Bearish)

## 🛠️ Tech Stack
- **Python** — Core language
- **Streamlit** — Web dashboard
- **yfinance** — Real market data
- **Plotly** — Interactive charts
- **Anthropic Claude API** — AI analysis

## ⚙️ Setup & Run

```bash
pip install yfinance streamlit plotly anthropic
streamlit run app.py
```
